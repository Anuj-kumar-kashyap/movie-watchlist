🎬Movie Watchlist
A responsive Movie Watchlist web application that allows users to search for movies using the TMDB API and save their favorite movies to a personal watchlist.

🚀Features
- 🔍 Search movies by title
- 🎞️ Fetch real-time movie data using TMDB API
- ⭐ Add movies to Watchlist
- ❌ Remove movies from Watchlist
- 💾 Watchlist stored using Local Storage
- 📱 Fully responsive design
- ⚡ Fast and lightweight interface

🛠️Tech Stack
- HTML5
- CSS3
- JavaScript (ES6)
- TMDB API
- Local Storage
